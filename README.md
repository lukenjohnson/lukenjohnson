I’m particularly interested in the point where software meets real organizational work. I aim to understand what a system needs to accomplish for the people using it, not merely what code needs to be written.

I use AI coding environments extensively to accelerate investigation, implementation, testing, and documentation while retaining human judgment and careful production controls.
